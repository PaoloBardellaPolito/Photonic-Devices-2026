# Photonic Devices 2026

This repository contains Python/Colab notebooks, numerical examples, and simulation resources developed for the **Photonic Devices** course.

The material is intended to complement the lectures with computational examples, numerical exploration, and simulation-based exercises.

## Contents

The repository will progressively include notebooks and resources covering different topics addressed during the course.

The material may include:

- numerical examples;
- interactive parameter sweeps;
- visualization of physical phenomena;
- analytical and numerical models;
- simulation examples;
- exercises for independent exploration.

## Running the notebooks

Most notebooks are designed to run directly in **Google Colab**, without requiring a local Python installation.

Each notebook can be opened in Colab using the link available in its accompanying README file, and executed cell by cell. Students are encouraged to modify parameters, rerun the calculations, and explore how the physical behavior changes.

Some simulation activities may require additional software or packages; specific instructions will be provided in the corresponding folders.
